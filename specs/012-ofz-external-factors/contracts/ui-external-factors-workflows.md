# UI Workflows: Внешние факторы активности ОФЗ

## Вкладка `Факторы`

- Расположение: summary panel рядом с `Сезонность`, `События`, `Сегменты`,
  `Спец`, `Ограничения`, `День`.
- Верхняя строка: краткий coverage text, например
  `факторов 4; наблюдений 35; missing 2; provisional 1`.
- Основная таблица: `Код`, `Фактор`, `Значение`, `Δ`, `Дата`, `Source`,
  `Статус`.
- Ниже: таблица связей с активностью: `Дата`, `Фактор`, `Связь`, `Оборот`,
  `Yield Δ`, `Текст`.
- Limitations показываются в той же вкладке, если фактор отсутствует или
  snapshot/provisional.

## Drill-down

- Finding по фактору ведет в summary tab `Факторы`.
- Если finding связан с датой, строка связи должна быть выбрана или видима
  после перехода.
- Если finding связан с issue-level special metric, existing issue detail
  остается primary drill-down, а факторная вкладка показывает market context.

## Text policy

Допустимые формулировки:

- `активность совпала с движением RGBI`
- `активный день прошел на фоне спокойной ключевой ставки`
- `factor evidence предварительный`

Недопустимые формулировки:

- `движение вызвано`
- `ожидается рост/снижение`
- `покупать`, `продавать`, `привлекательно`, `непривлекательно`
