# Feature Specification: Quality gates для OFZ summary/export

**Feature Branch**: `013-ofz-summary-quality-gates`
**Created**: 2026-05-10
**Status**: Draft
**Input**: User description: "После 012 закрепить повторяемые проверки summary JSON/export: ключевые секции, sourceCounts, date-only поля, no fake zero/n/a и наличие важных findings на реальных smoke-сценариях."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Защитить полный summary contract (Priority: P1)

Разработчик меняет аналитику ОФЗ и хочет быстро понять, не сломал ли итоговый
`OfzMarketSummary`/JSON contract для полного сценария с breadth, index,
cashflow, seasonality и external factors.

**Why this priority**: это основной риск после features 006-012: отдельные
unit-тесты могут проходить, но итоговый summary может потерять секцию,
`sourceCounts` или важный finding.

**Independent Test**: запустить targeted tests для quality gates; тест строит
полный representative summary и проверяет обязательные секции и счетчики.

**Acceptance Scenarios**:

1. **Given** representative OFZ summary input со сделками, activity metrics,
   index points, cashflow events, CBR rates и seasonality baseline, **When**
   строится summary, **Then** JSON содержит `breadthDays`, `indexContextDays`,
   `cashflowContext`, `seasonalityContext`, `externalFactorsContext`,
   `specialMetrics` и согласованные `sourceCounts`.
2. **Given** summary serializes to JSON, **When** quality gate проверяет даты,
   **Then** торговые даты в ключевых секциях сериализуются date-only, без
   time-компонента.

---

### User Story 2 - Не терять важные выводы из-за общего лимита (Priority: P2)

Разработчик добавляет новый вид выводов и хочет убедиться, что ключевые
контекстные выводы не вытесняются полностью общим `MaxFindings`.

**Why this priority**: после 012 был обнаружен реальный UX-риск: factor links
были в JSON и UI, но factor finding мог не попасть в top-level findings.

**Independent Test**: targeted test строит сценарий, где обычные выводы
заполняют top-7, и проверяет присутствие хотя бы одного обязательного
context finding при наличии соответствующих данных.

**Acceptance Scenarios**:

1. **Given** `externalFactorsContext.links` содержит связи с активностью,
   **When** итоговый список findings ограничен дефолтным лимитом, **Then**
   хотя бы один `ExternalFactorActivity` присутствует в top-level findings.
2. **Given** index/cashflow/seasonality contexts имеют evidence, **When**
   quality gate строит summary, **Then** связанные findings остаются
   нейтральными и не используют рекомендационный язык.

---

### User Story 3 - Зафиксировать missing-data политику (Priority: P3)

Разработчик меняет загрузчики или расчетные поля и хочет убедиться, что
отсутствующие значения не превращаются в `0`, фиктивный `n/a` или пустой
успешный результат без limitation.

**Why this priority**: для ОФЗ-ПК, ОФЗ-ИН, liquidity, index snapshot и external
factors корректная availability/limitations политика важнее красивых чисел.

**Independent Test**: targeted tests проверяют synthetic missing-data cases и
JSON serialization.

**Acceptance Scenarios**:

1. **Given** special metric или external factor недоступен, **When** строится
   summary, **Then** значение остается `null`/missing, а limitation явно
   описывает источник неполноты.
2. **Given** current snapshot/provisional данные попали в summary, **When**
   JSON serializes, **Then** `isSnapshot`/`isProvisional` и limitations
   сохраняются в соответствующих секциях.

### Edge Cases

- В выбранном периоде нет cashflow events, но `CashflowDataLoaded = true`.
- В периоде есть factor links, но все они `ActivityWithoutFactorMove`.
- `SignalScope = LastAvailableDay` ограничивает findings, но baseline и
  coverage-секции не должны терять исторические точки.
- Summary строится для одного coupon type, а часть секций содержит только
  market-wide context.
- Snapshot/provisional точка является последней датой периода.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: System MUST provide automated quality gate tests for the full
  OFZ summary/export contract after features 006-012.
- **FR-002**: Gates MUST verify presence of key summary sections:
  `breadthDays`, `indexContextDays`, `cashflowContext`,
  `seasonalityContext`, `externalFactorsContext`, `specialMetrics`,
  `limitations`, `sourceCounts`.
- **FR-003**: Gates MUST verify `schemaVersion = "1.6"` until a future feature
  explicitly bumps the schema.
- **FR-004**: Gates MUST verify that source counts are non-zero or explicitly
  zero according to the representative input, not silently absent.
- **FR-005**: Gates MUST verify date-only serialization for trade/event dates
  in representative JSON sections.
- **FR-006**: Gates MUST verify that no recommendation/causality language is
  present in findings generated by the representative summary.
- **FR-007**: Gates MUST verify that external factor links produce at least one
  top-level `ExternalFactorActivity` finding under the default `MaxFindings`.
- **FR-008**: Gates MUST verify missing-data behavior: missing special/factor
  values are not serialized as fake zero values.
- **FR-009**: Gates MUST be runnable from existing .NET test commands without
  requiring WPF automation, network access or a local `.tmp` export file.
- **FR-010**: Gates SHOULD use compact synthetic representative input in tests
  rather than committing large user export artifacts.

### Key Entities

- **SummaryQualityGate**: automated assertion set for a representative
  `OfzMarketSummary`.
- **RepresentativeSummaryScenario**: synthetic OFZ input covering breadth,
  index, cashflow, seasonality, external factors and missing-data cases.
- **ContractSectionExpectation**: required JSON section/source-count/date-only
  assertion for a summary export.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: `dotnet test -c Release --filter "FullyQualifiedName~OfzSummaryQualityGateTests"` passes and covers full summary contract.
- **SC-002**: Full `dotnet test -c Release` passes with the new gates enabled.
- **SC-003**: A regression that removes `externalFactorsContext`, factor
  source counts or `ExternalFactorActivity` from the representative summary
  fails at least one quality gate.
- **SC-004**: A regression that serializes missing special/factor values as
  `0` fails at least one quality gate.

## Assumptions

- Feature 013 is test/quality-gate work; it should not add new analytics,
  loaders, persistence schema or WPF UI.
- Representative scenarios can be synthetic as long as they cover the same
  contract surfaces as the manual smoke export.
- Existing `OfzMarketSummaryBuilder` remains the source of truth for summary
  construction.
- Large `.tmp/*.json` exports remain runtime artifacts and should not become
  required source files.
